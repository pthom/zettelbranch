# Security

Zettelbranch runs inside claude.ai, where it can see your conversations. If you find a way it could leak them, send anything to another site, or act without your click, please report it privately: [open a security advisory](https://github.com/pthom/zettelbranch/security/advisories/new) (GitHub's private vulnerability reporting), not a public issue.

What the code is supposed to never do, and the commands that check it, are in [AUDIT.md](AUDIT.md).
